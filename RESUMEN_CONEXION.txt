═══════════════════════════════════════════════════════════════════════════════
                            PASOS A SEGUIR
═══════════════════════════════════════════════════════════════════════════════

PASO 1: Obtener credenciales de Supabase (5 min)
  1. Ve a https://supabase.com
  2. Crea un proyecto nuevo o selecciona uno existente
  3. Ve a Settings → API
  4. Copia:
     - Project URL: https://xxxxx.supabase.co
     - Anon Public Key: eyJ0...

PASO 2: Abrir la app (1 min)
  $ cd /home/claude/finanzas-saas
  $ python -m http.server 3000
  
  Luego abre: http://localhost:3000

PASO 3: Llenar modal (1 min)
  - Pega Project URL en el campo "Project URL"
  - Pega Anon Key en el campo "Anon Public Key"
  - Presiona "Conectar Supabase"
  - Verás: ✅ Supabase conectado correctamente

PASO 4: Crear base de datos en Supabase (5 min)
  1. En Supabase → SQL Editor
  2. New Query
  3. Copia TODA el contenido de /database/schema.sql
  4. Pega y ejecuta (Run)

PASO 5: Crear bucket de almacenamiento (1 min)
  1. En Supabase → Storage
  2. New Bucket
  3. Nombre: invoices
  4. Privacidad: Private
  5. Create

TOTAL: 13 minutos ✅

                           SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: "El modal no aparece"
SOLUCIÓN: 
  - Asegúrate que config.js tiene valores DEFAULT (no configurados)
  - Recarga la página (Ctrl+Shift+R - limpia caché)
  - Abre consola (F12) y busca errores

PROBLEMA: "CORS error"
SOLUCIÓN:
  - Verifica que la URL NO termine en "/"
  - Copia la KEY completa (sin espacios)

PROBLEMA: "RLS deny" después de conectar
SOLUCIÓN:
  - Ejecuta el schema.sql en Supabase
  - Espera 30 segundos
  - Recarga la app

PROBLEMA: "Credenciales se pierden al recargar"
SOLUCIÓN:
  - localStorage está activo
  - Si cierras todo y vuelves a abrir, te pide credenciales de nuevo
  - O edita config.js manualmente (alternativa)
