PASO 2.1: Abrir Línea de Comandos
─────────────────────────────────

En tu PC (Windows, Mac o Linux):

WINDOWS:
  1. Presiona: Windows + R
  2. Escribe: cmd
  3. Presiona: ENTER

MAC:
  1. Presiona: Cmd + Espacio
  2. Escribe: terminal
  3. Presiona: ENTER

LINUX:
  1. Abre Terminal (Ctrl + Alt + T)

═══════════════════════════════════════════════════════════════════════════════

PASO 2.2: Ir a la Carpeta del Proyecto
──────────────────────────────────────

En la línea de comandos, escribe:

  cd /home/claude/finanzas-saas

Luego presiona ENTER.

(Si estás en Windows, podría ser diferente - pregunta)

═══════════════════════════════════════════════════════════════════════════════

PASO 2.3: Iniciar el Servidor Local
───────────────────────────────────

Escribe esto en la línea de comandos:

  python -m http.server 3000

Luego presiona ENTER.

Verás algo como:

  Serving HTTP on 0.0.0.0 port 3000 (http://0.0.0.0:3000/)

✅ ESO ES CORRECTO - El servidor está funcionando.

PASO 2.5: Pegar tus Credenciales
───────────────────────────────

EN EL PRIMER CAMPO ("Project URL"):
  1. Click en el campo (donde dice "https://xxxxx...")
  2. Presiona: Ctrl+A (para seleccionar todo)
  3. Presiona: Ctrl+V (para pegar)
  
  Debe quedar así:
  https://abcdefghijkl.supabase.co

EN EL SEGUNDO CAMPO ("Anon Public Key"):
  1. Click en el campo
  2. Presiona: Ctrl+A
  3. Presiona: Ctrl+V
  
  Debe quedar así:
  eyJ0eXAiOiJKV1QiLCJhbGc...

PASO 3.3: Copiar el Schema SQL
──────────────────────────────

Ahora necesitas el archivo schema.sql.

En tu PC, ve a la carpeta:
  /home/claude/finanzas-saas/database/

Ahí verás un archivo llamado:
  schema.sql

Abrelo con un editor de texto (Bloc de Notas, VSCode, etc).

Verás un archivo muy largo con código SQL (empieza con CREATE TABLE).

Selecciona TODO (Ctrl+A) y copia (Ctrl+C).

═══════════════════════════════════════════════════════════════════════════════

PASO 3.4: Pegar en Supabase SQL Editor
──────────────────────────────────────

Vuelve a la pestaña de Supabase con el SQL Editor abierto.

Verás un área blanca donde dice "-- Enter your SQL here":

┌──────────────────────────────────────────────────────────┐
│  New Query                                                │
│                                                            │
│  ┌──────────────────────────────────────────────────────┐ │
│  │ -- Enter your SQL here                               │ │
│  │                                                        │ │
│  │ [cursor aquí]                                         │ │
│  │                                                        │ │
│  │                                                        │ │
│  └──────────────────────────────────────────────────────┘ │
│                                                            │
│  ┌────────────────────────────────────────────────────┐  │
│  │ RUN (botón azul con triángulo ►)                   │  │
│  └────────────────────────────────────────────────────┘  │
│                                                            │
└──────────────────────────────────────────────────────────┘

1. Click en el área blanca (donde dice "-- Enter your SQL here")
2. Presiona Ctrl+A (selecciona todo lo que hay)
3. Presiona Ctrl+V (pega el schema.sql que copiaste)

Ahora verás TODO el código SQL en el editor.

═══════════════════════════════════════════════════════════════════════════════

────────────────────────────
