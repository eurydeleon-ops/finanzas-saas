INICIO RÁPIDO (5 minutos):
═════════════════════════════════════════════════════════════════════════════

1. CREAR PROYECTO SUPABASE
   → Ir a supabase.com
   → Crear proyecto
   → Copiar URL y ANON_KEY

2. EJECUTAR SCHEMA
   → Supabase → SQL Editor
   → Copiar contenido de sql/schema.sql
   → Ejecutar

3. CONFIGURAR APLICACIÓN
   → Editar js/config.js
   → Pegar URL de Supabase
   → Pegar ANON_KEY

4. PROBAR LOCALMENTE
   → python -m http.server 3000
   → Abrir http://localhost:3000

5. DESPLEGAR EN AZURE
   → Git push a GitHub
   → Azure Portal → Static Web Apps
   → Conectar GitHub → Deploy automático

6. ¡LANZAR!
   → Tu app en: https://tu-app.azurestaticapps.net
